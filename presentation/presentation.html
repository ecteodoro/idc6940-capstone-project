Model: two parts and one value

Sale probability
logit q(a) = β₀ + s(a) + X′β
Logistic + spline kept (log loss 0.526 vs boosted 0.529)
Price if sold
log(P/m) = γ₀ + h(a) + X′γ + ε
Boosted kept (RMSE $112 vs ridge $147)
U(a) = q(a) · [ p(a) − fee ] + [ 1 − q(a) ] · ( retained value − holding cost )
a = floor / benchmark value · m = benchmark · p = expected price if sold

Optimization: one floor per vehicle

maximize
Σᵢ Σₖ zᵢₖ · Uᵢ(aᵢₖ)
subject to
Σₖ zᵢₖ = 1 for every vehicle i
Σᵢ Σₖ zᵢₖ · qᵢ(aᵢₖ) ≥ Nτ
zᵢₖ ∈ {0, 1}

Solver: HiGHS through SciPy, 30-second limit, optimality gap 10⁻⁶
Candidates: floors seen in comparable training vehicles, plus common ratios and proportional cuts
The constraint is on expected conversion, not on one auction’s realized outcome

Conclusions and next steps

1
Findings
  • +$340 per vehicle vs a common ratio at 60%
  • Within $262 of the oracle
  • Cost of conversion rises sharply
2
Limits
  • Floor response is assumed
  • Private information is simulated
  • Conversion under-predicted for fleet/lease
3
Next
  • Decision-focused training
  • Repeated auctions (up to 3 attempts)
  • Validate on real auction data
Results apply to the simulated environments; real-auction performance is still an empirical question.
